<details>
  <summary><strong>🎓 M.Sc. Cybersecurity Engineering — Advanced Topics Investigated (Click to Expand)</strong></summary>
  <br/>
  
  - **Cryptography & Network Security (CNS)**:
    - Formal safety proofs of *Diffie-Hellman Ephemeral* vs Static Key Transport.
    - Analysis of TLS 1.3 protocol changes (removal of RSA key transport & CBC padding oracle vectors).
    - WEP IV collision paradoxes & IPsec (ESP vs AH) authenticated encryption guarantees.
